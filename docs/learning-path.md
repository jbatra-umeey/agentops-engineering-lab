# Suggested teaching path

**Phase 1 (weeks 1–2):** agent loop, ReAct, tools, schemas, planning.

**Phase 2 (weeks 3–4):** multi-agent coordination, supervisor, graph state, checkpoints, memory, context.

**Phase 3 (weeks 5–6):** RAG, MCP, approval, permissions, injection defense, structured output.

**Phase 4 (weeks 7–8):** reliability, idempotency, budgets, reproducibility, tracing, evaluation, cost, reflection.

**Capstone:** replace one simulated diagnostic tool with a secured real integration; add a model-backed planner behind a feature flag, trajectory evaluations, tracing, and a rollback plan. Present an architecture decision record and failure-injection results.
